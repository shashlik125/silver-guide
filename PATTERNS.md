# Внедрение паттерна Strategy

## Проблема
В проекте была жёстко прописана логика отправки уведомлений с множеством if/else, что усложняло добавление новых каналов.

## Решение
Внедрен паттерн Strategy:
- Создан интерфейс INotificationStrategy
- Реализованы классы EmailNotification, PushNotification, SmsNotification
- NotificationService использует выбранную стратегию для отправки уведомлений

## Результат
Код стал гибким и расширяемым — новые типы уведомлений добавляются без изменения существующего кода.

## Запуск
Выполнить `python main.py` для проверки работы уведомлений.
